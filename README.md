# my_project_2027

## دانلود LionXsec Shop

[دانلود مستقیم نسخهٔ ۱.۱۰.۰ فروشگاه با Gemma محلی و llama.cpp](https://github.com/alexsalar2029-lgtm/my_project_2027/raw/refs/heads/main/downloads/LionXsec-Shop-v1.10.0-local-gemma.zip)

لوگوی شیر روی پست‌های تلگرام، سربرگ و آیکون مرورگر؛ لینک سفارش صحیح `https://t.me/LionXSec`؛ بهبود عنوان و توضیحات و امکان بازنویسی مطالب قبلی.

نسخهٔ ۱.۱۰.۰، **llama.cpp + Gemma 3 4B تصویری** را برای جایگزینی Qwen اضافه می‌کند: تحلیل محلی بدون کلید یا هزینهٔ API، نصب‌کنندهٔ ویندوز با بررسی SHA-256، اجرای Vulkan برای AMD، حالت CPU و آزمون واقعی متن/تصویر. اجرای اول وزن‌های مدل را از Hugging Face دانلود می‌کند. بازیابی رسانهٔ تلگرام و صف پست‌ها از نسخهٔ قبلی حفظ شده‌اند.

برای به‌روزرسانی، برنامه و `watch` را متوقف و فایل‌ها را جایگزین کنید؛ **پوشهٔ `data` فعلی خود را حفظ کنید**. [راهنمای نصب ویندوز، حذف مدل Qwen و فعال‌سازی انتشار](LionXsec-Shop/LOCAL_AI_FA.md) را دنبال کنید. نصب‌کننده انتشار را تا پایان آزمون متوقف می‌کند و کانال، کلیدها و پست‌های قبلی را نگه می‌دارد.
