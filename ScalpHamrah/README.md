## آزمون همین نسخه

[اجرای موفق GitHub Actions شمارهٔ ۷](https://github.com/alexsalar2029-lgtm/my_project_2027/actions/runs/44753687947): ۷۵۴ آزمون Python، ۶ آزمون JVM، ساخت و lint، و ۱۰ آزمون آفلاین نصب/رابط روی هر کدام از اندروید ۸ و ۱۶ موفق شدند. تصاویر از شبیه‌ساز گرفته شده‌اند. اتصال به حساب کاربر و معاملهٔ زنده آزمایش نشده‌اند؛ ابتدا روی دمو بررسی کنید.

APK سه معماری ARM32، ARM64 و x86_64 دارد و حداقل Android 8 می‌خواهد. ۷۰ کتابخانهٔ ARM64 از نظر هم‌ترازی ۱۶ کیلوبایتی بررسی شده‌اند؛ این به معنی آزمون همهٔ گوشی‌ها نیست.

امضای این APK آزمایشی با نسخهٔ قبلی GitHub متفاوت است؛ ارتقای مستقیم روی نسخه‌ای با امضای متفاوت رد می‌شود. پیش از تصمیم به حذف نسخهٔ قبلی، موتور را متوقف و معاملات باز و استاپ را در ترندو بررسی کنید. حذف برنامه داده‌های محلی و نشست‌ها را پاک می‌کند و معاملهٔ بروکر را نمی‌بندد. [راهنمای نصب](USER_GUIDE_FA.md) را بخوانید. برای انتشار پایدار، کلید امضای ثابت هنوز باید در GitHub Secrets تنظیم شود.
