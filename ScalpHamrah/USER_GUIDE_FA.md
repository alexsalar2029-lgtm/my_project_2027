# راهنمای LionXsec 0.4.0

## آموزش بدون حساب

آموزش ← سیگنال‌خوانی یا Trendo ← کارت تصویری. هر درس تمام‌صفحه است؛ «تصویر بعد» یک کار را نشان می‌دهد. پخش خودکار اختیاری است. در درس فری، خرید و فروش را عوض کنید؛ در درس حجم، عددها را لمس کنید. تمرین آفلاین و جدول حجم هیچ حساب یا سفارش واقعی را تغییر نمی‌دهند. برای افراد کم‌سن، همین تمرین مجازی استفاده شود.

## اتصال تلگرام

۱. تنظیمات ← «۱ تلگرام». از پیوند سایت رسمی my.telegram.org، API ID و API Hash حساب خودتان را بگیرید؛ شماره را با + و کد کشور وارد کنید. این مقادیر را در پیام عمومی یا GitHub ننویسید.
۲. «دریافت کد تلگرام» را بزنید. آخرین کد را از تلگرام بخوانید و «تأیید ورود» را بزنید. اگر رمز دومرحله‌ای درخواست شد، آن رمز را وارد کنید؛ دکمه بدون کد جدید هم کار می‌کند.
۳. «بررسی کانال و دریافت ۳۰ پیام» را بزنید. پس از تأیید دسترسی، پیام‌ها در بخش سیگنال‌ها دیده می‌شوند. این پیام‌های پیشین اجرا نمی‌شوند. اگر ورود یا شبکه شکست بخورد، همان مرحله دلیل و راه اصلاح را نشان می‌دهد.
۴. برای دریافت پیوسته بدون معامله، در خانه «دستی و آموزشی» و سپس «دریافت پیام‌ها» را انتخاب کنید.

## انتخاب حساب ترندو

۱. تنظیمات ← «۲ حساب ترندو». ایمیل و رمز ورود Trendo را وارد کنید؛ این مرحله به API تلگرام نیاز ندارد.
۲. «دریافت حساب‌های من از ترندو» را بزنید. هیچ سفارش یا اتصال معاملاتی در این مرحله ایجاد نمی‌شود.
۳. «مجازی • دمو» یا «واقعی» را انتخاب و روی ردیف حساب موردنظر بزنید. شناسه و ارز ذخیره می‌شوند؛ نیازی به تایپ شناسه نیست. نوع نامعلوم و حساب‌های خارج از پشتیبانی برای معامله انتخاب نمی‌شوند. بونوس و کیف پول واریز، معادل حساب دمو نیستند.
۴. USD و EUR قابل انتخاب‌اند. حساب EUR برای محاسبهٔ حجم طلا به نرخ تازهٔ EURUSD از همان اتصال بروکر نیاز دارد؛ بدون آن سفارش ارسال نمی‌شود.
۵. انتخاب داخل LionXsec تعیین می‌کند موتور از کدام حساب استفاده کند. این انتخاب عنوان حساب داخل اپ ترندو را تغییر نمی‌دهد؛ شناسهٔ هر دو را خودتان تطبیق دهید. واریز، برداشت و ساخت حساب در خود ترندو انجام می‌شود.

## بازکردن اپ و اجرای خودکار

۱. تنظیمات ← «۳ اجرای گوشی»: Trendo نصب‌شده را انتخاب و «بازکردن Trendo» را آزمایش کنید. گزینهٔ «هنگام شروع خودکار، Trendo را باز کن» را در صورت نیاز فعال نگه دارید.
۲. بودجهٔ ریسک هر سیگنال و سقف افت روزانه را ذخیره کنید. سقف روزانه در ارز حساب است: مثلاً ۸ در حساب EUR یعنی ۸ یورو؛ این سقف محدودکنندهٔ ورود بعدی است و سقف تضمینی زیان نیست.
۳. به خانه بروید، «خودکار» و «شروع خودکار» را بزنید. حساب واقعی نیاز به تأیید روشن دارد. ابتدا روی دمو آزمایش کنید.
۴. پس از بازشدن ترندو، به LionXsec برگردید و وضعیت اتصال و شناسهٔ حساب فعال را بررسی کنید. در بخش سیگنال‌ها، پیام دریافت‌شده، علت تصمیم موتور و سفارش تأییدشده جدا هستند. پیام ناقص، قدیمی، تکراری یا خارج از کنترل ریسک الزاماً اجرا نمی‌شود.
۵. هنگام خروج، وضعیت «درخواست بستن» کافی نیست؛ حجم باقی‌مانده و تأیید بروکر معیار بسته‌شدن کامل‌اند. توقف موتور، سفارش‌های باز را نمی‌بندد و استاپ مجازی را متوقف می‌کند.

## اگر اتصال برقرار نشد

- خطای تنظیمات تلگرام: API ID، API Hash و شماره را کامل کنید. نشست LionXsec مستقل از تلگرام نصب‌شده است.
- کد اشتباه/منقضی: آخرین کد را وارد یا پس از محدودیت زمانی دوباره درخواست کنید.
- نرسیدن پیام: ابتدا بررسی کانال را اجرا کنید؛ سپس دریافت دستی یا خودکار را از خانه شروع کنید. عکس یا صدا بدون متن، سیگنال متنی کامل محسوب نمی‌شود.
- ورود ترندو رد شد: ایمیل و رمز ورود بروکر، اینترنت و دسترسی شبکه را بررسی کنید. خطای پاسخ سرویس ممکن است به تغییر API بروکر مربوط باشد؛ اتصال زنده در محیط ساخت تأیید نشده است.
- حساب خالی یا انتخاب‌نشده: حساب‌ها را دوباره دریافت و دقیقاً یک حساب را انتخاب کنید.
- EURUSD تازه نرسیده: موتور برای جلوگیری از حجم‌گیری اشتباه ورود نمی‌کند؛ وضعیت بازار، شبکه و جریان قیمت را بررسی کنید.

## نصب و سازگاری

حداقل Android 8/API26. APK سه معماری ARM32، ARM64 و x86_64 دارد؛ تضمین نصب یا کار روی همهٔ مدل‌ها نیست. شبیه‌سازهای قدیمی Android 7 مناسب نیستند. تنظیمات باتری Redmi/HyperOS و محدودیت سرویس اندروید می‌توانند اجرای پیوسته را متوقف کنند.

اگر نصب روی نسخهٔ قبلی به علت امضای متفاوت رد شد، پیش از تصمیم به حذف نسخهٔ قبلی، موتور را متوقف و معاملات و استاپ بروکر را بررسی کنید. حذف، داده‌های محلی و نشست‌ها را پاک می‌کند و نیازمند ورود دوباره است؛ سفارش‌های بروکر را نمی‌بندد. کلید انتشار ثابت برای توزیع بعدی هنوز باید تنظیم شود.
