# تلگرام‌یار برای ویندوز

[دانلود مستقیم TelegramPublisher-Windows.zip](https://github.com/alexsalar2029-lgtm/my_project_2027/raw/refs/heads/main/TelegramPublisher/TelegramPublisher-Windows.zip)

رابط گرافیکی فارسی برای ورود با حساب شخصی تلگرام، انتخاب پوشه، تشخیص نوع فایل، عنوان خودکار قابل‌ویرایش، صف ارسال و زمان‌بندی.

## اجرا

۱. ZIP را دانلود و از حالت فشرده خارج کنید.
۲. Python 3.12 نسخهٔ ۶۴ بیتی را از [python.org](https://www.python.org/downloads/windows/) با Python Launcher و Tcl/Tk نصب کنید.
۳. فایل `Start.vbs` را اجرا کنید؛ در اجرای نخست، نصب کتابخانه‌ها به اینترنت نیاز دارد. اگر VBS غیرفعال است، `Start.bat` را اجرا کنید.
۴. اطلاعات API، شماره و کد تأیید را داخل برنامه وارد کنید. راهنمای کامل در `راهنما.md` داخل بسته قرار دارد.

این بسته فایل EXE از پیش ساخته‌شده نیست. برای زمان‌بندی، برنامه و کامپیوتر باید روشن بمانند. اطلاعات ورود کاربر داخل بسته قرار ندارد.

عنوان‌ها از نام فایل و متادیتای PDF یا فایل صوتی ساخته می‌شوند؛ تحلیل محتوای عکس و ویدئو با هوش مصنوعی در این نسخه انجام نمی‌شود.

۱۷ آزمون خودکار موفق بوده‌اند. ورود واقعی تلگرام، Windows DPAPI، راه‌انداز ویندوز و ساخت EXE در این محیط آزموده نشده‌اند.
