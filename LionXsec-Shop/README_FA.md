# LionXsec Shop — v1.9.2 اصلاح پاسخ مدل و بازیابی صف

اگر وضعیت `account_mode` همراه با `model_response_invalid` می‌بینید، حالت حساب تلگرام فعال است اما پاسخ مدل هنگام خواندن یا اعتبارسنجی رد شده است. این نسخه قالب چهارزبانهٔ مشخص برای Ollama، پاسخ کوتاه‌تر، زمینهٔ ۱۶K، یک تلاش اصلاحی با علت دقیق و نمایش جزئیات خطا در پنل را اضافه می‌کند. عنوان چندخطی، زبان اضافه و هم‌پوشانی خلاصه/توضیحات پست کوتاه دیگر به‌تنهایی مانع انتشار نمی‌شوند.

برای بازیابی صف نسخهٔ قبلی:

1. سایت و دریافت‌کنندهٔ تلگرام را با Ctrl+C متوقف کنید؛ از `data` پشتیبان بگیرید.
2. همهٔ فایل‌های نسخهٔ جدید را جایگزین کنید و **پوشهٔ `data` خودتان را نگه دارید**؛ فایل‌های جدید `model_output.py` و `static/assistant-status.js` هم لازم‌اند.
3. Ollama را در حال اجرا نگه دارید و سایت و `python telegram_account.py watch` را دوباره اجرا کنید. نیازی به ورود مجدد تلگرام یا دانلود دوبارهٔ مدل موجود نیست.
4. پنل را با Ctrl+F5 بازخوانی کنید؛ در «دستیار تلگرام» دکمهٔ **تلاش دوباره موارد ناموفق / Retry failed posts** را بزنید. دستیار باید فعال باشد. همین کار با `python assistant.py retry-failed` نیز انجام می‌شود.
5. موارد `retry` و `failed` به `pending` برمی‌گردند. پست‌های منتشرشده و موارد قدیمی `ignored` تغییر نمی‌کنند. برای دیدن وضعیت تازه، تب دستیار را دوباره باز کنید. اگر پردازش دوباره ناموفق شود، نام فیلد/زبان یا علت قطع پاسخ نشان داده می‌شود.

گزارش بررسی این اصلاحیه در [MODEL_RECOVERY_VALIDATION.md](MODEL_RECOVERY_VALIDATION.md) است. علت قطعی صف واقعی کاربر از گزارش کلی نسخهٔ قبلی قابل تشخیص نیست؛ پاسخ‌های واقعی مدل روی دستگاه کاربر در این محیط آزمایش نشده‌اند.

این نسخه لوگوی کارت‌های دستیار تلگرام، لینک سفارش و کیفیت نگارش عنوان و توضیحات را اصلاح می‌کند. آدرس سفارش و پشتیبانی **https://t.me/LionXSec** است. لوگوی جدید، **سر شیر با یال طلایی و چشم‌های آبی** است و روی همهٔ کارت‌های دستیار تلگرام، سربرگ فروشگاه، پنل مدیریت و آیکون مرورگر نمایش داده می‌شود. فایل لوگو داخل برنامه است و از سایت خارجی بارگذاری نمی‌شود. لوگوی انتخابی محصولات دستی همچنان از پنل قابل تنظیم است.

دکمهٔ «سفارش در تلگرام» به راه ارتباطی فروشگاه وصل است و «مشاهده پست اصلی» جدا نمایش داده می‌شود. لینک پست کانال خصوصی جایگزین لینک سفارش نمی‌شود. لینک سفارش از «مدیریت ← شبکه‌های اجتماعی ← تلگرام» قابل تغییر است؛ آدرس قدیمی پیش‌فرض `link_Lion` به آدرس جدید ارتقا می‌یابد و آدرس‌های سفارشی حفظ می‌شوند. خالی‌کردن لینک اجتماعی، آیکون آن را مخفی می‌کند؛ سفارش و پشتیبانی از آدرس پیش‌فرض LionXSec استفاده می‌کنند.

عنوان‌سازی بر نام محصول، پلن و مشخصات واقعاً موجود در متن یا تصویر متمرکز شده است. عنوان‌های عمومی مثل «پیشنهاد ویژه» و نام خام فایل برای اصلاح به مدل برمی‌گردند. پست کوتاه می‌تواند خلاصه و توضیحات یکسان داشته باشد؛ بخش جزئیات تکراری در کارت نمایش داده نمی‌شود. قیمت، مدت، گارانتی و ویژگی ناموجود نباید ساخته شود. لوگوی شیر از فایل محلی نمایش داده می‌شود.

برای به‌روزرسانی، برنامه و دریافت‌کنندهٔ تلگرام را متوقف کنید، از پوشهٔ `data` پشتیبان بگیرید و فایل‌های این نسخه را در پوشهٔ فعلی برنامه جایگزین کنید؛ **پوشهٔ `data` خودتان را حذف یا جایگزین نکنید**. سپس برنامه را دوباره اجرا و صفحه را با Ctrl+F5 بازخوانی کنید. اصلاح لوگو و لینک روی پست‌های قبلی نیز اعمال می‌شود. برای بازنویسی عنوان و توضیحات قدیمی، در «مدیریت ← دستیار تلگرام» دکمهٔ **بازنویسی پست‌های منتشرشده** را بزنید. دستیار باید فعال و مدل قابل دسترس باشد؛ از همان مدل تنظیم‌شده استفاده می‌شود. پست فعلی تا تأیید جایگزین حفظ می‌شود و پست تکراری ایجاد نمی‌شود. در صورت استفاده از OpenAI، بازنویسی نیز مصرف API دارد.

همین عملیات از خط فرمان در پوشهٔ برنامه در دسترس است:

```bash
python assistant.py reprocess-published
```

گزارش آزمون‌های این نسخه و محدودیت بررسی اتصال واقعی در [PUBLISHING_FIX_VALIDATION.md](PUBLISHING_FIX_VALIDATION.md) است.

## قابلیت‌های نسخه‌های پیشین

نسخه ۱.۸ برای ویدیوهای تا ۱۰۰ مگابایت سه فریم از ابتدا، میانه و پایان استخراج می‌کند تا نوشتهٔ عنوان، برند و محتوای داخل ویدیو واقعاً به مدل تصویری برسد. ویدیو فقط داخل پوشه موقت سیستم دانلود می‌شود و بعد از استخراج فریم‌ها حذف می‌شود. `imageio-ffmpeg` با فایل requirements نصب می‌شود؛ نیازی به نصب دستی FFmpeg نیست.

اصلاح ۱.۷.۱ تشخیص آگهی فروش اشتراک، سرویس، ابزار، لایسنس و اکانت را برای مدل‌های محلی روشن‌تر می‌کند؛ فقط اطلاعات ورود، رمز، نشست و داده شخصی رد می‌شوند. فرمان `python assistant.py retry-ignored` مواردی را که قبلاً اشتباه نامرتبط شده‌اند دوباره صف می‌کند.

نسخه ۱.۷ حالت **Ollama محلی رایگان** را اضافه می‌کند. در این حالت تحلیل متن و تصویر روی همان کامپیوتر انجام می‌شود، کلید OpenAI لازم نیست و صف‌های retry/failed با دستور `python assistant.py retry-failed` فوراً دوباره صف می‌شوند. مدل پیشنهادی برای کامپیوترهای معمولی `qwen3-vl:4b` است.

نسخه ۱.۶ در حالت حساب کاربری، لینک دعوت کانال خصوصی را می‌پذیرد و پست‌های عکس/ویدیو را با کپشن، مشخصات رسانه و تصویر پیش‌نمایش برای تشخیص محتوا به مدل می‌فرستد. حساب باید از قبل عضو و مدیر کانال خصوصی باشد؛ برنامه خودکار عضو کانال نمی‌شود. فایل کامل ویدیو به OpenAI یا سایت منتقل نمی‌شود.

اصلاح ۱.۶.۱ لینک خصوصی را از نویسه‌های نامرئی و شکل‌های رایج `joinchat` پاک‌سازی می‌کند و به‌جای پیام عمومی، نام دقیق فیلد نامعتبر را در پنل نشان می‌دهد. فیلدهای کلیدی که علامت ✓ دارند باید برای حفظ مقدار ذخیره‌شده خالی بمانند.

روش دریافت با حساب تلگرام و App API ID/hash برای خواندن تاریخچه کانال اضافه شد. راهنما: [ACCOUNT_FA.md](ACCOUNT_FA.md). حالت ربات قبلی نیز قابل استفاده است. هیچ کلید یا نشست واقعی داخل فایل‌ها نیست.

نسخه جدید شامل تب «دستیار تلگرام» و انتشار خودکار محتوای کانال با OpenAI است. راه‌اندازی محلی، تنظیم ربات و کلید API، ورود تاریخچه و محدودیت‌ها در [ASSISTANT_FA.md](ASSISTANT_FA.md) توضیح داده شده‌اند. دستیار در نصب تازه غیرفعال است تا بعداً کانال خود را متصل کنید.

## امکانات تازهٔ ۱٫۲

- پنل «محصولات ← محصول جدید» شامل انتخاب لوگوی آماده و **آپلود لوگو از سیستم** است. PNG، JPG و WebP تا ۳ مگابایت پذیرفته می‌شود. برای پُرکردن سریع زبان‌های خالی، دکمهٔ «کپی این متن به زبان‌های خالی» را بزنید؛ این کار ترجمهٔ خودکار نیست و می‌توانید متن هر زبان را بعداً ویرایش کنید.
- قیمت هر واحد جدا نمایش داده می‌شود و **جمع همان تعداد** با دکمه‌های +/− یا تایپ تعداد فوراً تغییر می‌کند. قیمت هر ردیف و کل سبد هم هنگام تایپ به‌روز می‌شوند. محاسبهٔ نهایی همچنان روی سرور است.
- تب «آموزش‌های ویدیویی» در مدیریت برای افزودن عنوان و توضیحات چهارزبانه، آپلود فایل تا ۲۵۰ مگابایت و انتشار یا مخفی‌کردن آموزش است. محدودیت نوع فایل حذف شده است؛ هر فرمتی پذیرفته می‌شود و نوع آن روی سرور از محتوای واقعی فایل (امضای بایتی، در غیر این صورت پسوند یا تشخیص متن/باینری) شناسایی و برچسب MIME می‌خورد. در صفحهٔ فروشگاه، ویدیو و صوت با پخش‌کنندهٔ کنترل‌دار (جابه‌جایی از طریق HTTP Range)، تصویر با تگ img و سایر فایل‌ها به‌صورت دکمهٔ دانلود نمایش داده می‌شوند. پخش ویدیو و صوت نیازمند سازگاری codec با مرورگر است؛ برای MP4 معمولاً H.264/AAC مناسب است.
- تب «ابزارهای رایگان» برای افزودن، ویرایش و حذف عنوان، توضیحات و **لینک دانلود HTTPS** است. فایل ابزار را در هاست دلخواه خود قرار دهید و لینک آن را وارد کنید. سایت ابزارها را خودکار دانلود یا اجرا نمی‌کند.
- تب «فایل‌های آپلودشده» نام، حجم و نوع فایل‌ها را نشان می‌دهد. فایلِ استفاده‌شده در محصول یا آموزش قابل حذف نیست؛ ابتدا ارتباط را از آن محصول یا محتوا بردارید. لغو فرم می‌تواند فایلِ آپلودشدهٔ بدون استفاده باقی بگذارد که از این تب قابل حذف است.

فایل‌های لوگو و ویدیو در `data/media` و مشخصاتشان در SQLite ذخیره می‌شوند. **در به‌روزرسانی کل پوشهٔ `data` را نگه دارید.** ساخت جدول‌های تازه خودکار است و محصول‌ها، سفارش‌ها و رمز قبلی حفظ می‌شوند. هیچ ویدیو یا ابزار ساختگی برای فروشگاه فعال نشده است؛ محتوا را از پنل خودتان وارد کنید.

محتوا و رسانه برای نمایش عمومی طراحی شده‌اند. گزینهٔ «نمایش عمومی» فهرست‌شدن آموزش یا ابزار را کنترل می‌کند؛ فایل رسانه با داشتن لینک مستقیم قابل دریافت است و سامانهٔ آموزش پولی یا حفاظت دانلود نیست.

در nginx یا سرویس میزبانی، سقف بدنهٔ درخواست را حداقل `260m` تنظیم کنید تا آپلود ویدیو با خطای 413 رد نشود. زمان مجاز آپلود و فضای دیسک باید مناسب باشند. هیچ‌یک از آپلودهای شخصی در ZIP انتشار یا GitHub کپی نمی‌شوند.

طراحی نسخهٔ ۱٫۱ تیره و آبی است، با تصویر شیرِ چشم‌آبی، نشان هندسی شیر در سربرگ و آیکون مرورگر، و لوگوهای محلی NordVPN، Crunchyroll، DAZN، Netflix، Spotify، YouTube و Surfshark. در فرم محصول، «لوگوی سرویس» را انتخاب کنید. برای محصولاتی که لوگوی اختصاصی ندارند، نشان شیر LionXsec در دسترس است. لوگوها از سرور خود فروشگاه بارگذاری می‌شوند و به سرویس لوگوی خارجی وابسته نیستند.

برای به‌روزرسانی نصب قبلی، برنامه را متوقف کنید، از پایگاه داده پشتیبان بگیرید و فایل‌های برنامه را جایگزین کنید؛ پوشهٔ `data` خودتان را نگه دارید. محصولات و سفارش‌های قبلی خودکار جایگزین نمی‌شوند. برای محصولات قبلی، لوگو را از فرم ویرایش انتخاب کنید. در نصب تازه، شش محصول برنددار **نمونه** نمایش داده می‌شود؛ این‌ها موجودی یا قیمت واقعی نیستند و تا ویرایش مدیر قابل سفارش نیستند.

فروشگاه مستقل چهارزبانه (فارسی، انگلیسی، عربی و اسپانیایی) برای فروش عمدهٔ اشتراک دیجیتال. حداقل هر محصول ۵ عدد است. قیمت‌ها به USDT، پرداخت با USDT روی BEP-20 یا Litecoin، و تأیید پرداخت و تحویل کاملاً دستی از طریق [@LionXSec](https://t.me/LionXSec) انجام می‌شود. سایت به درگاه، صرافی یا بات تلگرام وصل نمی‌شود.

عنوان صفحه به «خرید عمده اکانت پرمیوم با گارانتی و خرید ابزارهای خصوصی کمیاب» تغییر کرده و ترجمه‌های انگلیسی، عربی و اسپانیایی هم به‌روز شده‌اند.
بالای سایت، آیکون یوتیوب به `https://www.youtube.com/@ComboList-qe7yy` و تلگرام به `https://t.me/LionXSec` متصل است و با کلیک در تب جدید باز می‌شود.
برای تغییر لینک‌ها وارد پنل مدیریت و تب «شبکه‌های اجتماعی» شوید. یوتیوب، تلگرام، اینستاگرام، X، دیسکورد، واتساپ، گیت‌هاب و تیک‌تاک قابل تنظیم‌اند؛ فقط شبکه‌های دارای لینک نمایش داده می‌شوند. لینک خالی آیکون را پنهان می‌کند. لینک باید HTTPS و متعلق به همان شبکه باشد.
هنگام به‌روزرسانی، فایل جدید `social.py` و فایل‌های جدید داخل `static` را هم کپی کنید و پوشهٔ `data` نصب قبلی خود را حفظ کنید. نیازی به ساخت دوباره محصولات یا سفارش‌ها نیست.

## اجرای محلی

Python 3.11 یا جدیدتر کافی است؛ وابستگی خارجی ندارد. در پوشهٔ پروژه:

```bash
python server.py init-admin
python server.py
```

دستور اول رمز مدیریت را بدون نمایش در ترمینال می‌گیرد. رمز پیش‌فرض وجود ندارد و حداقل ۱۲ نویسه لازم است. دستور دوم فروشگاه را روی پورت ۸۰۰۰ اجرا می‌کند. در مرورگر همان دستگاه نشانی `http://127.0.0.1:8000` را باز کنید؛ نشانی پنل `http://127.0.0.1:8000/admin` است. برای توقف Ctrl+C بزنید. در ویندوز می‌توانید از `start.bat` استفاده کنید؛ بار اول نیز رمز را تنظیم می‌کند.

## تنظیم فروشگاه

1. در پنل، نمونه‌ها را ویرایش یا حذف کنید و نام، مدت و روش تحویل را در چهار زبان وارد کنید. قیمت، به USDT و برای هر عدد است. ذخیرهٔ محصول نمونه آن را به محصول عادی تبدیل می‌کند.
2. آدرس عمومی دریافت USDT روی BEP-20 و/یا آدرس اصلی Litecoin را ثبت کنید. کلید خصوصی و عبارت بازیابی لازم نیست و نباید وارد شود. بررسی فرمت و checksum آدرس LTC انجام می‌شود؛ مالکیت آدرس و شبکهٔ مقصد با مدیر است. فرمت آدرس `0x` به‌تنهایی شبکه را مشخص نمی‌کند: مطمئن شوید کیف پول یا صرافی شما USDT روی BNB Smart Chain را می‌پذیرد.
3. برای LTC، ارزش یک LTC به USDT را دستی وارد کنید و حداقل هر ۲۴ ساعت به‌روز کنید. نرخ قدیمی یا آدرس خالی، همان روش پرداخت را غیرفعال می‌کند. تبدیل با Decimal و گردکردن رو به بالا تا ۸ رقم اعشار انجام می‌شود. منبع قیمت آنلاین و نرخ فرضی وجود ندارد.
4. تا زمان وجود محصول واقعی و روش پرداخت آماده، سفارش عملیاتی ثبت نمی‌شود. نمونه‌ها فقط برای نمایش‌اند و سرور سفارش آن‌ها را رد می‌کند.

## سفارش و پرداخت

مشتری از هر محصول ۵ تا ۱۰۰۰۰ عدد انتخاب می‌کند. سرور مستقل از مرورگر قیمت و حداقل تعداد را کنترل می‌کند. سفارش شامل تصویر ثابتی از محصول، مدت، قیمت، روش تحویل، آدرس دریافت و نرخ تبدیل است؛ ویرایش یا حذف بعدی محصول، سفارش قبلی را عوض نمی‌کند.

مبلغ اعلامی هر سفارش ۳۰ دقیقه اعتبار دارد. پس از پایان زمان، مشتری باید پیش از پرداخت با پشتیبانی هماهنگ کند. سفارش خودکار «پرداخت‌شده» یا «لغوشده» نمی‌شود؛ پرداخت دیرهنگام نیازمند تطبیق دستی است. مبلغ USDT دقیقاً از قیمت USDT محاسبه می‌شود؛ سایت فرض تبدیل USDT به دلار نقدی نمی‌کند.

دکمهٔ تلگرام فقط گفت‌وگو را با پیش‌نویس متن باز می‌کند. هیچ پیامی خودکار ارسال نمی‌شود. اگر کلاینت تلگرام متن را وارد نکرد، مشتری «کپی متن سفارش» را می‌زند و متن را خودش می‌فرستد. ارسال تصویر رسید یا شناسهٔ تراکنش در تلگرام انجام می‌شود؛ آپلود فایل در سایت وجود ندارد.

در بخش سفارش‌های مدیریت، تراکنش را در شبکهٔ صحیح بررسی کنید و سپس وضعیت را تغییر دهید. تأیید پرداخت یا تحویل به تیک تأیید دستی نیاز دارد. گذارهای مجاز:

- منتظر پرداخت ← در حال بررسی / پرداخت تأیید شد / لغو
- در حال بررسی ← پرداخت تأیید شد / لغو
- پرداخت تأیید شد ← تحویل داده شد

وضعیت تحویل صرفاً ثبت انجام کار مدیر است؛ سایت فایل یا اطلاعات اکانت ارسال نمی‌کند. شناسهٔ تراکنش و یادداشت داخلی در API عمومی سفارش نمایش داده نمی‌شوند. پنل آخرین ۵۰۰ سفارش را نشان می‌دهد؛ همهٔ سفارش‌ها در پایگاه داده حفظ می‌شوند.

پیگیری سفارش با یک توکن تصادفی در مرورگر مشتری انجام می‌شود؛ شمارهٔ سفارش به‌تنهایی اجازهٔ مشاهده نمی‌دهد. پاک‌کردن داده‌های مرورگر می‌تواند پیگیری محلی را حذف کند؛ مشتری همچنان با شمارهٔ سفارش از تلگرام پیگیری می‌کند.

## میزبانی واقعی

این پروژه یک بک‌اند با SQLite دارد و با آپلود فایل‌های HTML روی هاست استاتیک یا Netlify Static عملیاتی نمی‌شود. Python را روی VPS یا سرویس دارای دیسک پایدار اجرا کنید و HTTPS را با reverse proxy فراهم کنید. اطلاعات در `data/shop.sqlite3` نگهداری می‌شود؛ پوشهٔ `data` باید پایدار و خارج از مسیر فایل‌های عمومی باشد.

نمونهٔ اجرای پشت reverse proxy روی همان VPS:

```bash
PUBLIC_ORIGIN=https://shop.example.com python server.py --port 8000
```

نشانی بالا نمونه است؛ دامنهٔ واقعی خودتان را جایگزین کنید. nginx یا Caddy باید درخواست‌های دامنه را به پورت ۸۰۰۰ روی loopback بفرستد. با `PUBLIC_ORIGIN` از نوع HTTPS، کوکی مدیریت Secure می‌شود و کنترل Origin با دامنهٔ تنظیم‌شده تطبیق داده می‌شود. TLS را پیش از ورود مدیریت فعال کنید. دامنه یا هاست عمومی در این کار ثبت یا منتشر نشده است.

رمز مدیریت با PBKDF2-SHA256 ذخیره می‌شود؛ نشست‌های تصادفیِ سمت سرور ۸ ساعت عمر دارند و تغییر رمز همهٔ نشست‌ها را لغو می‌کند. نوشتن در API مدیریت به نشست و CSRF token نیاز دارد. ورود و ثبت سفارش محدودیت نرخ دارند. در تنظیم پشت پروکسی، این محدودیت بر اساس آدرس اتصال پروکسی مشترک اعمال می‌شود؛ برای ترافیک واقعی rate limit جداگانهٔ مبتنی بر IP در reverse proxy تنظیم کنید. برنامه عمداً به هدرهای قابل جعل `X-Forwarded-For` اعتماد نمی‌کند.

پشتیبان‌گیری هماهنگ SQLite:

```bash
python backup.py shop-backup.zip
```

پشتیبان ZIP شامل SQLite و فایل‌های آپلودشدهٔ ثبت‌شده در پایگاه داده است. پشتیبان شامل اطلاعات سفارش‌ها و حساب مدیریت است؛ آن را عمومی نکنید. برای بازیابی یا جابه‌جایی، سرویس را متوقف کنید و محتوای پشتیبان را در پوشهٔ `data` قرار دهید. مقصد با پسوند `.sqlite3` فقط از دیتابیس پشتیبان می‌گیرد و رسانه‌ها را شامل نمی‌شود. فایل ZIP توزیع برنامه شامل هیچ رمز، کیف پول واقعی، سفارش، آپلود شخصی یا پایگاه داده‌ای نیست.

## اعتبارسنجی

```bash
python -m unittest discover -s tests -v
```

آزمون‌ها از پایگاه دادهٔ موقت و درخواست HTTP محلی استفاده می‌کنند؛ هیچ پرداخت یا پیام تلگرام واقعی انجام نمی‌شود. کنترل تعداد، محاسبهٔ قیمت سمت سرور، نرخ و گردکردن LTC، انقضای نرخ، تصویر ثابت سفارش، دسترسی مدیریت، CSRF و گذارهای دستی وضعیت پوشش داده شده‌اند.
