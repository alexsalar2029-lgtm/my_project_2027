# دستیار هوش مصنوعی تلگرام — نسخه ۱.۹.۲

## تحلیل رایگان روی کامپیوتر با Ollama

نسخه ۱.۷ می‌تواند به‌جای OpenAI از Ollama روی همان Windows استفاده کند. Ollama را از سایت رسمی نصب کنید و سپس در CMD اجرا کنید:

```cmd
ollama pull qwen3-vl:4b
```

در پنل، «روش تحلیل هوش مصنوعی» را روی «Ollama محلی رایگان» و مدل را روی `qwen3-vl:4b` قرار دهید. در این حالت کلید OpenAI لازم نیست. Ollama باید هنگام پردازش باز و سرویس محلی آن روی `127.0.0.1:11434` فعال باشد. مدل ۴B حدود ۳٫۳ گیگابایت دانلود دارد؛ مدل `qwen3-vl:2b` سبک‌تر ولی ضعیف‌تر است. پس از تغییر ارائه‌دهنده اجرا کنید:

```cmd
python assistant.py retry-failed
```

در نسخهٔ ۱.۹.۲، دکمهٔ «تلاش دوباره موارد ناموفق» در پنل همین کار را انجام می‌دهد. موارد قدیمی «نامرتبط / ignored» با این دکمه دوباره صف نمی‌شوند. راهنمای خطای پاسخ مدل و بازیابی صف در [README_FA.md](README_FA.md) آمده است.

متن و تصویر پیش‌نمایش رسانه به سرویس محلی Ollama فرستاده می‌شود و از رایانه خارج نمی‌شود. دانلود مدل به اینترنت نیاز دارد و سرعت تحلیل به RAM، CPU و GPU دستگاه وابسته است.

در نسخه ۱.۸، دریافت‌کننده برای ویدیوی حداکثر ۱۰۰ مگابایت سه فریم JPEG از ابتدا، میانه و پایان استخراج می‌کند. این کار باعث می‌شود عنوان و نوشته‌های داخل ویدیو نیز دیده شوند. فایل ویدیو در پوشه موقت ساخته و بلافاصله حذف می‌شود؛ فقط سه فریم در صف محلی ذخیره و برای مدل انتخاب‌شده ارسال می‌شوند. برای نصب استخراج‌کننده اجرا کنید:

```cmd
python -m pip install -r requirements-account.txt
```

این نسخه پست‌های کانال انتخاب‌شده را دریافت می‌کند، برای تحلیل و بازنویسی چهارزبانه به OpenAI می‌فرستد و خودکار در سایت محلی منتشر می‌کند:

- فروش: عنوان، خلاصه، جزئیات و قیمت مستند در بخش «پیشنهادهای کانال» داخل بخش فروش؛ دکمه سفارش راه ارتباطی فروشگاه (پیش‌فرض https://t.me/LionXSec) را باز می‌کند و لینک پست اصلی جدا نمایش داده می‌شود. پیشنهادها خودکار وارد سبد خرید نمی‌شوند؛ قیمت/موجودی قطعی و شرایط محصولات فروشگاهی همچنان در سیستم سفارش موجود مدیریت می‌شوند.
- آموزش: متن آموزشی در بخش آموزش‌های کانال. در حالت حساب کاربری، تصویر پیش‌نمایش عکس/ویدیو برای تشخیص محتوا به مدل فرستاده می‌شود؛ فایل کامل ویدیو در سایت کپی نمی‌شود و لینک پست اصلی نمایش داده می‌شود.
- مقاله/خبر: در بخش مطالب و تازه‌ها.
- پست نامرتبط: منتشر نمی‌شود.

دستیار کد سایت را بازنویسی نمی‌کند؛ محتوای پایگاه داده را به‌روزرسانی می‌کند و سایت آن را هر ۳۰ ثانیه دریافت می‌کند. نیازی به تأیید دستی تک‌تک پست‌ها نیست. عنوان و متن با مدل تولید می‌شوند و ممکن است خطا داشته باشند؛ متن اصلی و لینک منبع مبنای بررسی هستند. قیمت عددی فقط با تطبیق مقدار و واحد USDT/USD/EUR در متن اصلی نمایش داده می‌شود؛ در غیر این صورت «استعلام قیمت» می‌آید. هدف مدل حفظ شرایط و گارانتی واقعی پست است، نه ساختن ادعای جدید.

## شروع محلی

Python 3.11 یا جدیدتر با کتابخانه‌های استاندارد کافی است:

```cmd
python server.py init-admin
python server.py
```

مرورگر همان دستگاه: `http://127.0.0.1:8000`، پنل: مسیر `/admin`.
بار اول رمز حداقل ۱۲ نویسه تعیین کنید؛ اجرای دوباره init-admin رمز مدیر را عوض می‌کند.

در پنل مدیریت تب «دستیار تلگرام» وجود دارد. می‌توانید اکنون آن را غیرفعال نگه دارید و بعداً تنظیم کنید:

1. از BotFather یک ربات اختصاصی بگیرید و آن را به کانال تحت مدیریت خود اضافه کنید؛ برای دریافت پست کانال، در صورت نیاز آن را مدیر کنید. اجازه ارسال/حذف پیام برای این برنامه لازم نیست. برنامه هیچ پیام تلگرامی ارسال نمی‌کند.
2. شناسه `@your_channel` یا شناسه عددی `-100…`، توکن ربات و کلید API شخصی OpenAI را فقط در پنل محلی وارد کنید. مدل پیش‌فرض `gpt-4.1-mini` است و باید در حساب API شما قابل استفاده باشد. اشتراک ChatGPT جای اعتبار API را نمی‌گیرد.
3. «فعال‌سازی انتشار خودکار» را انتخاب و ذخیره کنید. در زمان اجرای عادی server.py، پردازشگر خودکار شروع می‌شود. ترمینال سایت باید باز بماند.
4. برای مشاهده وضعیت و آخرین پست‌ها، تب دستیار را دوباره باز کنید. وضعیت running یعنی آخرین دریافت موفق بوده؛ شمارنده‌ها وضعیت پردازش هر پست را نشان می‌دهند.

متن پست‌ها به سرویس OpenAI ارسال می‌شود و هزینه API دارد. اینترنت و دسترسی به api.telegram.org و api.openai.com لازم است. فقط کانال انتخاب‌شده پردازش می‌شود. از یک ربات مشترک با برنامه دیگر استفاده نکنید: getUpdates فقط باید یک مصرف‌کننده داشته باشد. برنامه webhook موجود را حذف نمی‌کند؛ در این وضعیت خطا نشان می‌دهد و باید ربات اختصاصی تنظیم کنید.

کلیدها در `data/assistant-config.json` محلی با مجوز محدود در Linux ذخیره می‌شوند؛ در پاسخ API مدیریت بازگردانده نمی‌شوند. این فایل رمزگذاری نشده است؛ پوشه data و بکاپ آن خصوصی باشد. در Windows، دسترسی پوشه را به حساب خود محدود کنید. مقدار خالی کلید در فرم، کلید قبلی را حفظ می‌کند. متغیرهای OPENAI_API_KEY و TELEGRAM_BOT_TOKEN نیز در صورت خالی بودن تنظیمات قابل استفاده‌اند. برای توقف دریافت خودکار تیک فعال‌سازی را بردارید؛ درخواست در حال اجرا ممکن است کامل شود.

## تاریخچه کانال

Bot API تاریخچه کامل کانال را نمی‌دهد و به‌روزرسانی‌های دریافت‌نشده را معمولاً بیش از ۲۴ ساعت نگه نمی‌دارد. پس از افزودن ربات، پست‌های جدید دریافت می‌شوند. پست‌های حذف‌شده اطلاع‌رسانی حذف ندارند و خودکار از سایت حذف نمی‌شوند. ویرایش متن یک پست دریافت‌شده، همان مورد سایت را به‌روزرسانی می‌کند.

برای پست‌های قدیمی در Telegram Desktop کانال را به JSON خروجی بگیرید. شناسه عددی کانال را در تنظیمات دستیار ثبت کنید. مقدار id خروجی معمولاً مثبت است؛ نسخه Bot API با پیشوند -100 استفاده می‌شود. سپس در پوشه سایت اجرا کنید:

```cmd
python assistant.py import-history "C:\Exports\result.json"
```

شناسه خروجی باید با کانال تنظیم‌شده منطبق باشد. ورود JSON فقط متن/کپشن را وارد می‌کند؛ تحلیل تصویر پیش‌نمایش مخصوص دریافت زنده با `telegram_account.py watch` است. پس از فعال‌سازی دستیار، صف خودکار پردازش می‌شود. آرشیوهای خروجی حاوی محتوای خصوصی را در مسیر static نگذارید.

## پایداری و خطاها

صف، شناسه پست و offset دریافت در SQLite ذخیره می‌شوند. دریافت دوباره همان پست، رکورد تکراری نمی‌سازد. ویرایش پست همان رکورد را جایگزین می‌کند؛ دو پست مستقل با متن مشابه دو مورد مستقل‌اند. انتشار و ثبت وضعیت در یک تراکنش انجام می‌شود. خرابی مدل یا پاسخ نامعتبر باعث انتشار متن ناقص نمی‌شود. خطاها تا ۵ بار با فاصله افزایشی تکرار و بعد failed می‌شوند؛ علت کلی در پنل ثبت می‌شود. پس از رفع مشکل، برای تلاش مجدد:

```cmd
python assistant.py retry-failed
```

فعلاً ۳۰۰ مورد جدید در سایت نمایش داده می‌شود؛ اطلاعات قدیمی در SQLite باقی می‌ماند. برنامه برای امنیت، HTML مدل را اجرا نمی‌کند و لینک سفارش از تنظیمات فروشگاه، مستقل از لینک پست اصلی، ساخته می‌شود.

برای نصب روی نسخه قبلی، ابتدا از data بکاپ بگیرید، فایل‌های برنامه را جایگزین کنید و data خود را نگه دارید. محصولات و سفارش‌های قبلی پاک نمی‌شوند. این نسخه به‌صورت پیش‌فرض هیچ کانال و هیچ کلید واقعی ندارد و غیرفعال است.
