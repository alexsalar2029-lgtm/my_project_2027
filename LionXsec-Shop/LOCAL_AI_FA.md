# اجرای محلی Gemma با llama.cpp — نسخهٔ ۱.۱۰.۰

این نسخه برای جایگزینی `qwen3-vl:4b`، موتور [llama.cpp](https://github.com/ggml-org/llama.cpp) و **Gemma 3 4B تصویری با کوانتیزهٔ Q4_K_M** را اضافه می‌کند. تحلیل روی کامپیوتر خودتان انجام می‌شود و هزینه یا کلید API ندارد. موتور llama.cpp تحت مجوز MIT است؛ وزن‌های Gemma مجوز جداگانهٔ [Gemma Terms](https://ai.google.dev/gemma/terms) دارند.

برای کامپیوتر دارای ۱۶ گیگابایت RAM و AMD Radeon RX590 GME، مسیر اول **Vulkan** است. سازگاری نهایی به درایور کارت بستگی دارد. حالت **CPU** هم در دسترس است و ممکن است تحلیل هر پست چند دقیقه طول بکشد. سرعت و کیفیت واقعی این مدل روی دستگاه شما هنوز اندازه‌گیری نشده است.

## نصب و حذف مدل قبلی

1. سایت و `telegram_account.py watch` را با Ctrl+C متوقف کنید و از پوشهٔ `data` پشتیبان بگیرید.
2. فایل‌های نسخهٔ جدید را در پوشهٔ برنامه جایگزین کنید. **پوشهٔ `data`، فایل نشست تلگرام و تنظیمات خودتان را نگه دارید.** Python 3.11 یا جدیدتر لازم است؛ نصب دوبارهٔ وابستگی‌های تلگرام یا ورود مجدد لازم نیست.
3. برای حذف مدل قبلی، در CMD اجرا کنید:

   ```bat
   ollama rm qwen3-vl:4b
   ```

   این فرمان روی کامپیوتر شما وزن‌های همین مدل را حذف می‌کند. فایل ZIP فروشگاه نمی‌تواند مدل نصب‌شده در ویندوز شما را از راه دور حذف کند. سپس Ollama را ببندید تا مدل دیگری حافظه را اشغال نکند. برنامهٔ جدید برای Gemma به Ollama وابسته نیست.

4. در پوشهٔ فروشگاه، **`setup-local-ai.bat`** را اجرا کنید؛ یا در CMD:

   ```bat
   python local_ai.py setup
   ```

   نصب‌کننده فایل رسمی Windows x64 نسخهٔ **b11960** را از GitHub دانلود و SHA-256 آن را قبل از استخراج بررسی می‌کند. اسکریپت راه دور اجرا نمی‌شود. روش تحلیل به `llamacpp` و مدل به `lionxsec-gemma-3-4b` تغییر می‌کند. **انتشار تا پایان آزمون غیرفعال می‌شود**؛ کانال، کلیدها، نشست، صف و پست‌های قبلی حفظ می‌شوند. اجرای دوبارهٔ `setup` نیز انتشار را متوقف می‌کند؛ برای استفادهٔ روزمره فقط `start` را اجرا کنید.

5. **`start-local-ai.bat`** را اجرا کنید؛ یا:

   ```bat
   python local_ai.py start
   ```

   اجرای اول، مدل و فایل بینایی `mmproj` را از مخزن [ggml-org/gemma-3-4b-it-GGUF](https://huggingface.co/ggml-org/gemma-3-4b-it-GGUF) دریافت می‌کند. این دانلود چند گیگابایت است و اینترنت لازم دارد؛ حداقل حدود ۱۰ گیگابایت فضای خالی برای مدل و فایل‌های موقت در نظر بگیرید. GitHub موتور را میزبانی می‌کند؛ وزن‌های مدل از Hugging Face می‌آیند. متن و تصویر پست‌ها برای تحلیل به این سایت‌ها فرستاده نمی‌شوند.

   پنجره را باز نگه دارید و صبر کنید بارگذاری کامل شود. سرویس فقط روی `127.0.0.1:8081` گوش می‌دهد؛ سایت همچنان روی پورت خودش اجرا می‌شود. یک پست در هر نوبت پردازش می‌شود. مدل و موتور در `.local-ai` ذخیره می‌شوند و در ZIP پروژه یا Git قرار نمی‌گیرند.

## آزمون واقعی، سپس فعال‌کردن انتشار

6. در حالی که پنجرهٔ مدل باز است، **`test-local-ai.bat`** را در پنجرهٔ جدا اجرا کنید؛ یا:

   ```bat
   python local_ai.py test
   ```

   ابتدا بارگذاری مدل و بخش بینایی بررسی می‌شود. سپس مدل باید رنگ یک تصویر آزمایشی را تشخیص دهد و برای یک آگهی نمونه، متن فارسی، انگلیسی، عربی و اسپانیایی همراه قیمت صحیح بسازد. خروجی از همان اعتبارسنجی پست‌های سایت عبور می‌کند. این آزمون پست‌های واقعی شما را نمی‌خواند، منتشر نمی‌کند و تغییر نمی‌دهد.

   موفقیت با **`llamacpp_test_passed` و `PASS`** اعلام می‌شود و زمان دو درخواست گزارش می‌شود. این آزمون اتصال ساده نیست؛ بسته به سخت‌افزار زمان می‌برد. موفقیت آن نیز تضمین کیفیت همهٔ پست‌ها نیست؛ اولین پست واقعی را از نظر عنوان و جزئیات بررسی کنید.

7. پس از موفقیت، سایت را با **`start.bat`** اجرا و پنل را با Ctrl+F5 تازه کنید. در «دستیار تلگرام» روش **llama.cpp · Gemma 3 (local)** و نام **`lionxsec-gemma-3-4b`** را بررسی کنید، «فعال‌سازی انتشار خودکار» را علامت بزنید و ذخیره کنید. کلید OpenAI لازم نیست.
8. دریافت‌کنندهٔ تلگرام را در پنجرهٔ جدا اجرا کنید:

   ```bat
   python telegram_account.py watch
   ```

   اگر قبلاً برای بازیابی تصاویر ناقص بازخوانی نکرده‌اید، برای یک بار می‌توانید از `python telegram_account.py watch --rescan-limit 200` استفاده کنید. دریافت‌کننده باید همچنان اجرا بماند.

9. دکمهٔ **«تلاش دوباره موارد ناموفق»** را یک بار بزنید. پست‌های `Pending` خودکار نوبت می‌گیرند. پست‌های قبلاً منتشرشده باقی می‌مانند؛ برای بازنویسی آن‌ها با Gemma، دکمهٔ جداگانهٔ «بازنویسی پست‌های منتشرشده» را بزنید. متن قبلی تا آماده‌شدن جایگزین نمایش داده می‌شود.

در اجرای روزمره، پنجرهٔ مدل، سایت و `watch` باید باز باشند. بعد از دانلود کامل، برای شروع مدل بدون اتصال به مخزن مدل از این فرمان استفاده کنید؛ دریافت پست‌های تلگرام همچنان اینترنت می‌خواهد:

```bat
python local_ai.py start --offline
```

دکمهٔ «بررسی سرویس محلی» در پنل فقط آماده‌بودن سرویس، مدل صحیح و بخش بینایی را بررسی می‌کند. آزمون تولید متن همان `test-local-ai.bat` است.

## اگر Vulkan اجرا نشد

پنجرهٔ مدل را ببندید. سپس در CMD، داخل پوشهٔ فروشگاه:

```bat
python local_ai.py setup --backend cpu
python local_ai.py start --backend cpu
```

پنجرهٔ دوم را برای `python local_ai.py test` باز کنید. پس از موفقیت، انتشار را دوباره فعال کنید. حالت CPU از بستهٔ اجرایی جداگانه استفاده می‌کند؛ وزن‌های دانلودشده در پوشهٔ مشترک حفظ می‌شوند. شروع‌های بعدی با `python local_ai.py start --backend cpu --offline` امکان‌پذیر است. نصب CUDA یا ROCm برای این مسیر لازم نیست.

## معنی خطاها

| پیام | اقدام |
| --- | --- |
| `llamacpp_connection_refused` | پنجرهٔ `start-local-ai.bat` را باز کنید و خطای احتمالی آن را ببینید. |
| `llamacpp_loading` | دانلود/بارگذاری هنوز تمام نشده؛ صبر کنید. تلاش‌های صف در این مرحله مصرف نمی‌شوند. |
| `llamacpp_model_mismatch` | سرویس پورت 8081 با نام مدل سایت مطابقت ندارد؛ برنامهٔ صحیح را از همین پوشه اجرا کنید. |
| `llamacpp_vision_unavailable` | بخش تصویری بارگذاری نشده؛ دانلود مدل و `mmproj` باید هر دو کامل شوند. |
| `llamacpp_out_of_memory` یا خطای Vulkan در پنجرهٔ مدل | برنامه‌های پرمصرف را ببندید؛ حالت CPU بالا را امتحان کنید. |
| `llamacpp_connection_timeout` | زمان پاسخ تمام شده؛ مهلت تحلیل ۳۰ دقیقه است. خروجی پنجرهٔ مدل و بار سیستم را بررسی کنید. |
| `llamacpp_context_exceeded` | متن/تصاویر این پست از ظرفیت زمینهٔ ۱۶K بیشتر است. پست نگه داشته می‌شود؛ متن ناقص خودکار منتشر نمی‌شود. |
| `llamacpp_vision_test_failed` | مدل رنگ تصویر نمونه را درست تشخیص نداده؛ انتشار را هنوز فعال نکنید. |
| `llamacpp_copy_test_failed` یا `model_…` | نمونهٔ چهارزبانه از بررسی محتوا/ساختار عبور نکرد؛ کد دقیق و مرحلهٔ آزمون را بررسی کنید. |
| خطای دانلود GitHub/Hugging Face | اتصال همان کامپیوتر به مخزن مربوط را بررسی و فرمان را دوباره اجرا کنید. حالت `--offline` فقط بعد از دانلود کامل کاربرد دارد. |
| `download_checksum_mismatch` | ZIP اجرایی داخل `.local-ai` ناقص یا متفاوت است؛ همان ZIP را حذف و `setup` را دوباره اجرا کنید. |
| نبودن `VCRUNTIME140.dll` | بستهٔ [Microsoft Visual C++ Redistributable x64](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist) را از مایکروسافت نصب کنید. |

`GetFileRequest` و `telegram_media_timeout` مربوط به دریافت رسانه از تلگرام‌اند. تعویض مدل اتصال تلگرام را تعمیر نمی‌کند. بازیابی رسانهٔ نسخهٔ ۱.۹.۴ حفظ شده است؛ پست فاقد تصویر لازم تا دریافت رسانه به مدل فرستاده نمی‌شود.

لوگوی شیر و لینک سفارش **https://t.me/LionXSec** حفظ شده‌اند. مدل‌های قبلی Ollama و OpenAI برای سازگاری با تنظیمات موجود در برنامه باقی هستند؛ انتخاب Gemma هیچ بازگشت خودکاری به سرویس آنلاین ندارد.

## اجرای دستی روی سیستم‌های دیگر

نصب‌کنندهٔ خودکار مخصوص Windows x64 است. در سیستم‌های دیگر، نسخهٔ رسمی llama.cpp سازگار با سیستم‌عامل را نصب کنید و `llama-server` را با این پارامترها اجرا کنید:

```sh
llama-server -hf ggml-org/gemma-3-4b-it-GGUF:Q4_K_M --alias lionxsec-gemma-3-4b --host 127.0.0.1 --port 8081 --ctx-size 16384 --parallel 1 --batch-size 512 --ubatch-size 128 --cache-ram 0 --no-context-shift --no-webui --cors-origins localhost --no-cors-credentials
```

سپس روش و نام مدل بالا را در پنل ذخیره کنید و `python local_ai.py test` را اجرا کنید. این مسیر به Ollama نیاز ندارد. گزارش آزمون‌های انجام‌شده و محدودیت محیط توسعه: [LOCAL_AI_VALIDATION.md](LOCAL_AI_VALIDATION.md).
