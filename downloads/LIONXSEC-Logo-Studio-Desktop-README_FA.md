# LIONXSEC — لوگوساز دسکتاپ ویندوز

این پروژه در پنجرهٔ مستقل روی کامپیوتر اجرا می‌شود. فایل اجرایی شروع، مرورگر را باز نمی‌کند و برای طراحی، حساب ChatGPT یا سایت آنلاین لازم نیست.

## اجرا در ویندوز ۱۰ و ۱۱

1. فایل ZIP را دانلود کنید و با **Extract All** از حالت فشرده خارج کنید. برنامه را از داخل ZIP اجرا نکنید.
2. پوشهٔ `LIONXSEC-Logo-Studio` را باز کنید.
3. روی **START-LIONXSEC.cmd** دوبارکلیک کنید.
4. بار اول به اینترنت وصل باشید تا پیش‌نیازها در پوشهٔ `.venv` نصب شوند. بعد، پنجرهٔ LIONXSEC باز می‌شود. دفعات بعد طراحی و ذخیرهٔ خروجی بدون اینترنت کار می‌کنند.

**پیش‌نیازها:** Python نسخهٔ ۳٫۱۰ تا ۳٫۱۳ (ترجیحاً ۳٫۱۳، ۶۴ بیتی) و Microsoft Edge WebView2 Runtime. فایل شروع نسخهٔ مناسب Python را پیدا می‌کند. پنجرهٔ ترمینال را تا پایان استفاده نبندید؛ بستن پنجرهٔ لوگوساز برنامه را تمام می‌کند.

اگر Python نصب نیست، از [python.org](https://www.python.org/downloads/windows/) نصب کنید و گزینهٔ **Add python.exe to PATH** را فعال کنید. WebView2 معمولاً روی ویندوز نصب است؛ در صورت خطای نبود آن، نسخهٔ Evergreen Runtime را از [سایت Microsoft](https://developer.microsoft.com/microsoft-edge/webview2/) نصب کنید.

## استفاده

- نام پیش‌فرض **LIONXSEC** است؛ نام فارسی یا انگلیسی و شعار دلخواه وارد کنید.
- یکی از ۶ نماد شیر را انتخاب کنید و رنگ، فونت و چیدمان را تغییر دهید.
- «دریافت لوگو» را بزنید؛ SVG، PNG یا آیکون را انتخاب کنید.
- پنجرهٔ **Save As** ویندوز باز می‌شود. مسیر و نام فایل را انتخاب کنید. پسوند فایل را حفظ کنید؛ اگر منصرف شدید، Cancel را بزنید.
- بستهٔ برند ZIP شامل لوگوی رنگی، سفید و مشکی، نسخهٔ افقی، نماد مستقل، PNG و آیکون سایت است.
- طرح‌ها به‌طور خودکار روی همین کامپیوتر ذخیره می‌شوند. «ذخیرهٔ طرح» آن را به «طرح‌های من» اضافه می‌کند.

## محل نگهداری طرح‌ها

`%LOCALAPPDATA%\LIONXSEC\LogoStudio\designs.json`

برای پشتیبان‌گیری از طرح‌ها این فایل را کپی کنید. جابه‌جایی یا به‌روزرسانی پوشهٔ برنامه، طرح‌های این مسیر را حذف نمی‌کند. خروجی‌های لوگو در مسیری ذخیره می‌شوند که خودتان در Save As انتخاب می‌کنید.

## اجرای دستی

در ترمینالِ پوشهٔ پروژه:

```bat
python setup_desktop.py
.venv\Scripts\python.exe app.py
```

برای اجرای تست‌های بخش ذخیره‌سازی:

```bat
python -m unittest discover -s tests -p "test_*.py"
```

## محتویات

- `app.py`: پنجرهٔ دسکتاپ با pywebview و موتور WebView2 ویندوز.
- `desktop_api.py`: ذخیرهٔ طرح روی دیسک و پنجرهٔ Save As.
- `ui/`: رابط فارسی، فونت‌ها و شش طرح برداری شیر؛ همهٔ فایل‌ها همراه پروژه هستند.
- `setup_desktop.py` و `requirements.txt`: نصب پیش‌نیازها در محیط مستقل.

این نسخه پروژهٔ قابل اجرا با Python است، نه فایل EXE از پیش کامپایل‌شده. لوگوها از طرح‌های برداری قابل ویرایش ساخته می‌شوند؛ سرویس هوش مصنوعی یا کلید API لازم نیست. مجوز فونت‌ها و کتابخانهٔ OpenType در `ui/assets/` قرار دارد.
